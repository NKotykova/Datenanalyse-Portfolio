### Projekte
***

### 1. NYC Taxi Data Analysis
Explorative Datenanalyse von 6.471 Taxifahrten in New York City (März 2019).  
Untersucht wurden Umsatzstruktur, Trinkgeldverhalten, Passagiergruppen und regionale Unterschiede zwischen den Boroughs.  
**Technologien:** Excel · Power Query · Power Pivot · PowerPoint  
[Zum Projekt](https://github.com/NKotykova/NYC-Taxi-Data-Analysis)

### 2. Immobilienpreis-Rechner
Grafische Desktop-Anwendung zur Schätzung des Immobilienwertes in Deutschland auf Basis von 10 Eingabeparametern (Fläche, Baujahr, Bundesland, Ausstattung u.a.).  
**Technologien:** Python · tkinter · JSON  
[Zum Projekt](https://github.com/NKotykova/Immobilienpreis_rechner)

### 3. Business Analyse – Restaurant Manuel's
Fiktives Lehrprojekt zur Anwendung klassischer Business-Analyse-Methoden anhand eines Restaurantszenarios.  
**Methoden:** SWOT · Kosten-Nutzen-Analyse · 5-Why · MoSCoW · Risikomatrix · MVP · Gantt  
[Zum Projekt](https://github.com/NKotykova/Business-Analyse)

### 4. Shop Daten Analyse
Verkaufsanalyse eines Fair-Trade-Dienstleisters für das Jahr 2021 (Deutschland & Europa, 3 Produkte).  
**Technologien:** Python · pandas · matplotlib · seaborn · PowerPoint  
[Zum Projekt](https://github.com/NKotykova/Shop_analyse)  

### 5. Datenbankprojekt — Aufbau einer PostgreSQL-Datenbank
Normalisierung einer Excel-Tabelle und Aufbau einer relationalen Datenbank mit Rollen, Sicherheits-Views und Zugriffsprotokollierung. Erweiterte Datenanalyse mit SQL und Python.  
**Technologien:** PostgreSQL · DBeaver · pgAdmin · Python · pandas · SQLAlchemy · Jupyter  
[Zum Projekt](https://github.com/NKotykova/Datenbankprojekt)

### 6. API-Projekt - Dog Breed Filter
Abruf und Filterung von Hunderassen über eine öffentliche API. Konfiguration mit .env-Datei, Ergebnisse werden lokal als CSV gespeichert. Klare Trennung von Konfiguration und Logik.
**Technologien:** Python · requests · pandas · python-dotenv · scipy
[Zum Projekt](https://github.com/NKotykova/Dog-Api-Project)  

### 7. Datenvisualisierung — World Happiness Dashboard
Analyse des World Happiness Reports 2018 und 2019. Interaktives Dashboard mit Weltkarte, Korrelationsmatrix, Scatter- und Bubble-Charts sowie Ranking mit Dumbbell- und Radar-Charts. Statistische Analyse mit OLS, VIF und PCA.
**Technologien:** Python · Streamlit · Plotly · pandas · NumPy · SciPy
[Zum Projekt](https://github.com/NKotykova/Happiness-App)
